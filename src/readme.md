## 五、数据流示意图
```
时间步 t:
┌─────────────────────────────────────────────────────────────┐
│                    输入数据                                   │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  感知质量maps          兴趣度map           位置                │
│  [N_v, H, W]          [H, W]             [N_v, 2]           │
│  (车辆视角)            (全局视角)          (空间坐标)          │
│      ↓                   ↓                  ↓                │
│  ┌─────────┐        ┌─────────┐       ┌─────────┐          │
│  │ VAE     │        │ CNN     │       │ MLP     │          │
│  │ Encoder │        │ Encoder │       │ Encoder │          │
│  └─────────┘        └─────────┘       └─────────┘          │
│      ↓                   ↓                  ↓                │
│  [N_v, 128]          [1, 64]           [N_v, 32]            │
│      ↓                   ↓                  ↓                │
│      └─────────repeat────┴──────concat──────┘               │
│                          ↓                                   │
│                   [N_v, 224] → Fusion → [N_v, 256]          │
│                                                               │
└─────────────────────────────────────────────────────────────┘
                              ↓
                    存储为 features_t
                              ↓
┌─────────────────────────────────────────────────────────────┐
│               收集所有时间步 t=0,1,...,T-1                     │
│               features_history = [N_v, T, 256]               │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                   时空建模 (ST-GNN)                           │
│  ┌──────────────────────────────────────────────────┐       │
│  │  For each t:                                     │       │
│  │    - 空间：GAT聚合车辆间信息                       │       │
│  │    - 时间：Transformer/LSTM建模演化               │       │
│  └──────────────────────────────────────────────────┘       │
│                      ↓                                       │
│              vehicle_embeddings                              │
│                  [N_v, 512]                                  │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                 Q值生成器 (CNN Decoder)                       │
│  ┌──────────────────────────────────────────────────┐       │
│  │  For each vehicle:                               │       │
│  │    embedding → FC → reshape → ConvTranspose      │       │
│  │              → 上采样 → Q值map                     │       │
│  └──────────────────────────────────────────────────┘       │
│                      ↓                                       │
│                  q_maps                                      │
│                [N_v, H, W]                                   │
└─────────────────────────────────────────────────────────────┘
